### ‹ منصة عربية أصيلة لدوري روشن السعودي: الترتيب، الأندية، اللاعبون، والمباريات المباشرة.

منصة رياضية متخصصة في كرة القدم السعودية فقط: جدول الترتيب، الهدافون، الجولات، صفحات الأندية بهوية وألوان كل نادٍ، وبطاقات لاعبين بإحصائيات بصرية. كل عنصر في الموقع يمكن إظهاره أو إخفاؤه من لوحة التحكم.

**An Arabic, RTL-native home for the Roshn Saudi League: tables, clubs, players and live matches.**

A sports platform dedicated to Saudi football only: standings, top scorers, matchweeks, club pages that adopt each club's own colours, and player cards with visual stats. Every element on the site can be toggled from the admin panel.

## `>` Features · المزايا

| Feature | الميزة |
|:--|--:|
| Per-club pages with the club's identity, colours and honours | صفحة لكل نادٍ بهويته وألوانه وبطولاته |
| One reusable player card with a stats back-face | بطاقة لاعب موحّدة بوجه خلفي للإحصائيات |
| Team of the season on horizontal/vertical pitch with bottom sheet | تشكيلة الموسم على ملعب أفقي/عمودي مع Bottom sheet |
| Live centre, categorised news with RSS | مركز مباشر، أخبار بتصنيفات وRSS |
| King's Cup, Super Cup, AFC Champions League Elite & ACL Two | كأس الملك، السوبر، أبطال آسيا للنخبة وآسيا 2 |
| Dark/light themes and reduced-motion support | وضع ليلي/نهاري واحترام prefers-reduced-motion |

## `<>` Architecture · البنية

| Layer | Details |
|:--|:--|
| **Stack** | PHP · MySQL · vanilla JS |

| **SEO** | Indexable club, player and match pages |
